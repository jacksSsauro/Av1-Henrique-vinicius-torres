# Projeto Av1-Henrique-vinicius-torres

Este projeto é uma aplicação web simples com HTML, CSS e JavaScript usando a seguinte estrutura:

- `index.html`
- `css/style.css`
- `js/script.js`

## Como rodar

1. Abra `index.html` no navegador (duplo clique ou via servidor local).
2. Modifique os arquivos em `css` e `js` conforme necessário.

## Objetivo

Exercício de prática de frontend para disciplinas de programação (AV1).
